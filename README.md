# RemoteShadow

Пульт администратора Windows-домена в одном окне: shadow-подключение к сессиям пользователей, RDP и SSH, управление пользователями Active Directory и диагностика «почему не подключается».

Только для Windows. Написан на C# / .NET 10, интерфейс на WPF (тема Fluent, светлая/тёмная/системная).

> **Статус: версия 0.1.0, ранний выпуск.** Логика покрыта 1857 автоматическими тестами, интерфейс проверен в демо-режиме. **На настоящем домене Active Directory и реальном shadow-подключении программа ещё не проверялась** — пробуйте сначала на тестовом стенде. Фаза проверки допущений (`spikes/ShadowSpike`) описана ниже.

## Скачать

Готовая сборка для Windows x64 — на странице [Releases](https://github.com/iamrlufe/RemoteShadow/releases/latest): файл `RemoteShadow-<версия>-win-x64.zip`. Распакуйте и запустите `RemoteShadow.exe`.

Чтобы посмотреть интерфейс без домена, запустите демо-режим:

```powershell
.\RemoteShadow.exe --demo
```

В демо-режиме работает тестовый домен `corp.local` (219 компьютеров, пользователи, сессии), ничего реального не затрагивается и никакие программы не запускаются. Вход: любой логин и пароль `demo`. Логин `da-…` — привилегированная учётная запись; `locked`, `disabled`, `expired`, `unreachable` показывают соответствующие ошибки входа.

## Возможности

### Компьютеры
- Список компьютеров из AD с поиском по имени и описанию, кэшем и обновлением (полная перезагрузка из AD — `Ctrl+F5`).
- **Доступность** по нескольким протоколам: ICMP, RDP, SMB, SSH, с DNS-разрешением имён. Статусы проверяются сами при открытии страницы и смене фильтров (если в области не больше 300 компьютеров), либо кнопкой «Обновить статусы».
- **Фильтры и сортировка:** доступность, источник (AD / найдено сканированием), протоколы, IP, подразделение, имя, описание, «показывать отключённые»; сортировка по доступности, имени, IP, времени проверки. Строка «Действуют условия» всегда объясняет, почему список короче.
- **Избранное** и **свои группы компьютеров** (создание, переименование, удаление).
- **Подсети и сканирование:** добавьте подсеть в CIDR (`/22`, `/24`, `/25`, `/31`, `/32`), просканируйте ICMP и/или TCP (445, 3389, 22). Найденные устройства сопоставляются с компьютерами AD по обратному DNS, остальные помечаются «вне AD». Сканирование запускается только вручную.
- Действия с выбранным компьютером: **RDP**, **SSH**, открыть **C$**, **перезагрузить**, **выключить**.

### Сессии и shadow
- Для компьютера видны его сессии: кто залогинен, активна ли.
- **Shadow** к сессии: просмотр или управление, с запросом согласия пользователя или без него (галочка «без запроса пользователю»; работает, только если это разрешено групповой политикой на целевом компьютере).
- Действия с сессией: отправить сообщение, отключить, завершить (выйти из системы) с указанием причины.

### Пользователи AD
- Поиск по фамилии/логину (от 2 символов).
- Сброс пароля (свой или сгенерированный, с требованием смены при входе), разблокировка, включение и отключение учётной записи, добавление в группу и удаление из группы, список групп пользователя.

### Диагностика
- Проверка выбранного компьютера: почему не работает shadow или подключение (доступность, службы, брандмауэр, политика shadow и др.) с итоговым вердиктом и подсказкой «что исправить».
- Кнопка «Исправить» появляется только там, где исправление доступно.
- «Скопировать отчёт» — текст отчёта без паролей и секретов.

### Поиск и удобство
- Общий поиск `Ctrl+K`: компьютер или пользователь, переход сразу к нужной записи.
- Горячие клавиши: `Ctrl+1…4` — разделы, `Ctrl+F` — поиск в разделе, `F5` — обновить, `Enter` — главное действие строки, правая кнопка — все действия, `F1` — справка по клавишам.
- Сворачиваемые панели фильтров и групп, окно запоминает размер и положение.
- Один запущенный экземпляр на папку данных.

### Вход и безопасность
- Два режима: **текущий пользователь** (Kerberos, без пароля) или **явные учётные данные** (удобно на компьютере вне домена). Перед входом учётные данные проверяются, ошибки объясняются понятно: неверный пароль, учётная запись заблокирована, недоступен контроллер домена, DNS не разрешает домен.
- Пароль хранится в памяти (защита `CryptProtectMemory`), по желанию — в Диспетчере учётных данных Windows; для привилегированных групп (Domain Admins и др.) сохранение пароля запрещено. Пароли не попадают в журнал, настройки и аргументы командной строки.
- Опасные действия (завершение сессии, перезагрузка, сброс пароля) требуют подтверждения.
- **Журнал действий:** время, кто, что, над чем, причина, результат — в `%AppData%\RemoteShadow\audit\yyyy-MM.jsonl`. Это история для самого администратора, не защищённый аудит.
- Внешние программы запускаются со списком аргументов (без `cmd /c`), имена компьютеров проверяются заранее.

Рекомендуется отдельная учётная запись с делегированными правами (управление пользователями в нужных OU и локальный администратор на рабочих станциях через GPO), а не Domain Admin.

## Требования

- Windows 10/11 или Windows Server 2016+.
- Права локального администратора на целевых компьютерах.
- Для shadow на целевых компьютерах: групповая политика, разрешающая удалённое управление сессиями, и открытые в брандмауэре правила «Remote Desktop - Shadow (TCP-In)» и SMB (445).
- На компьютере вне домена: DNS или VPN, разрешающие имена домена (подключаться нужно по FQDN, не по IP), и запущенная служба «Вторичный вход в систему» (`seclogon`).
- Для SSH — встроенный клиент OpenSSH Windows.

## Сборка из исходников

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download) (версия закреплена в `global.json`).

```powershell
git clone https://github.com/iamrlufe/RemoteShadow
cd RemoteShadow
dotnet build RemoteShadow.sln
dotnet test RemoteShadow.sln
dotnet run --project src/RemoteShadow.App -- --demo
```

Ветка `main` — стабильная, `development` — текущая разработка.

## Устройство проекта

| Проект | Назначение |
|---|---|
| `RemoteShadow.Core` | модели, интерфейсы, чистая логика (CIDR, фильтры, разбор имён) |
| `RemoteShadow.Infrastructure` | запуск действий, журнал, настройки, сеть и доступность |
| `RemoteShadow.Windows` | LDAP, WTS, учётные данные Windows, вход в домен |
| `RemoteShadow.Windows.Hosts` | проверки хостов: ICMP, TCP, CIM |
| `RemoteShadow.Modules` | встроенные модули: Connection, Sessions, Power, Users, Diagnostics |
| `RemoteShadow.Demo` | тестовый домен для `--demo` |
| `RemoteShadow.App` | WPF-оболочка и страницы |
| `spikes/ShadowSpike` | консольная проверка допущений на настоящем домене ([инструкция](spikes/ShadowSpike/README.md)) |

Новые функции добавляются отдельными модулями — см. [архитектуру](docs/ARCHITECTURE.md#расширяемость-модули-действия-страницы).
