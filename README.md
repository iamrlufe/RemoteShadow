# RemoteShadow

Пульт администратора Windows-домена в одном окне: shadow-подключение к сессиям пользователей, RDP и SSH, управление пользователями Active Directory и диагностика.

> **Статус:** проектирование. Кода пока нет — см. [план](docs/PLAN.md).

## Что будет уметь

- **Компьютеры** из AD по подразделениям, с поиском и статусом онлайн
- **Сессии** на компьютере: кто залогинен, активен ли, сколько простаивает
- **Shadow** к сессии пользователя: просмотр или управление, с запросом или без запроса пользователю
- **Поиск пользователя** по фамилии: на каком компьютере он сейчас и в какой сессии
- **RDP и SSH** к серверам
- **Действия с сессией:** сообщение, отключение, выход, перезагрузка компьютера
- **Пользователи AD:** сброс пароля, разблокировка, включение и отключение, группы
- **Диагностика:** почему не работает shadow и что исправить
- **Журнал:** кто, когда и что делал

Программа только для Windows. На компьютере в домене работает от текущего пользователя или под другой учётной записью, а на компьютере вне домена спрашивает логин и пароль. Рекомендуется отдельная учётная запись с делегированными правами, а не Domain Admin.

Новые функции добавляются отдельными модулями — см. [архитектуру](docs/ARCHITECTURE.md#расширяемость-модули-действия-страницы).

## Требования

- Windows 10/11 или Windows Server 2016+
- Права администратора на целевых компьютерах
- На компьютере вне домена: DNS или VPN, разрешающие имена домена, и запущенная служба «Вторичный вход в систему» (`seclogon`)
- На целевых компьютерах: групповая политика, разрешающая удалённое управление сессиями, и открытые в брандмауэре правила «Remote Desktop - Shadow (TCP-In)» и SMB (445). Подробности будут в документации по настройке.
